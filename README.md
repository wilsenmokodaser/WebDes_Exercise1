# WebDes_Exercise1 — Wisata Bunaken

Exercise Web Design 1: website profil wisata Taman Nasional Bunaken,
Sulawesi Utara. Universitas Klabat.

## Isi

- `index.html` — halaman utama (Tentang, Daya Tarik, Galeri, Tiket, Pesan)
- `style.css` — stylesheet
- `images/` — foto-foto Bunaken

## Menjalankan

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
python -m http.server 8000
```

lalu buka http://localhost:8000
